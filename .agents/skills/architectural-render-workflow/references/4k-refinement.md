# 4K 分区精修

## 母图与分区

1. 锁定用户授权的具体母图，记录视角、版本、文件、原生尺寸和 SHA-256。列出机位、构图、可见家具、边界、光色和明确允许调整的局部。仍属设计回改的问题单列，按本轮授权范围处理。
2. 按原比例计算目标尺寸。指定长边 3840 时，令短边为原短边乘以 3840 除以原长边后取整。要求固定画布时先核对比例及所需裁切或留边。
3. 按构件安排重叠分区。窗框、连续檐口、木格栅、家具组、主树、水岸和瀑布尽量由完整分区覆盖。重叠处保留两图区共同可识别的构件或纹理。记录每个分区的编号、母图坐标、目标画布坐标和裁切尺寸。
4. 按每区裁图重建细节。写清应保留的构造、视角、遮挡及光色。记录实际提示词、候选、原生生成尺寸与最终缩放倍率。需要纯放大时按用户要求交付，并写明所用方法。

## 配准与拼合

- 用稳定结构边线或特征匹配将分区配准到母图。SIFT 加相似变换是可选方案。优先验证窗框、檐线和家具脚等位置，并记录残差的单位及参照分辨率。配准后仍有结构偏差时，按整块重做或保留必要的母图区域。
- 用母图和重叠区校准分区曝光、白平衡与低频明暗。保持原图的光向和局部亮暗。选缝避开关键结构，再按实际需要羽化或多频段融合，检查全画幅覆盖。
- 限域修补另存新版本。记录蒙版及合成方式。若要求区外像素一致，在无损格式上比较蒙版外像素差，留存检查结果。

## 验收与导出

- 等比全景对照检查构图、结构、家具件数、受光方向和色阶。按最终尺寸 100% 查看窗框、檐边、格栅、树干、水岸和水丝，重点找跨区错齿、重影、断线和光色断层。
- 按需求交付全幅 PNG、JPG 或预览，附重点局部和接缝对照。记录实际尺寸、母图和输出哈希、分区坐标、执行提示词、生成取舍、接缝与可见残差。工程尺寸与细部重建属于不同的验证范围。
- 未取得实际分区生成结果时，把已完成内容标为分区方案或纯放大，交付状态与实际操作一致。

**6 号 V33 案例。** 1714 × 918 母图由 8 个重叠分区重建为 3840 × 2057。复核上层玻璃内退、檐底、灯带和瀑脚水雾，窗框与树干分叉用 100% 局部检查。分区数量和切法随构件、画幅及生成尺寸调整。
