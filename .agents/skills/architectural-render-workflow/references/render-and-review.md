# 标注、渲染与评审

## 标注与输入分工

1. 从建模软件导出当前机位的干净白模并保存原始画幅。有原模型时记下对应机位和比例依据。需在多轮间固定底图时留快照，记录像素尺寸和 SHA-256。
2. 材质图标明结构、玻璃、铺装、水体的边界及材质差异。配景图标明家具方向、件数、落地、植栽层次、水岸和通行。用编号把总图与檐下、窗口、平台或水口大样联系起来。光感参考写清光源方向、受光面、暗部层次和色温。
3. 给每张参考写一句用途。照片里的树形、家具或高光可按指定内容借鉴，参考照片自身的透视由项目机位重新确定。类似的辅助形状可能有不同含义，先按用户原话和图例确认用途。

## 生成与回改

- 提示词按「机位与几何 → 本轮改动 → 必须保留 → 材质、光色、配景 → 验收点」排列。用可见关系说明需求，例如「透过轻纱只露出靠近开口的一小段椅背，桌面被木平台挡住」。
- 对直边找同一方向的白模参照，核桌沿、灯槽、柜顶和平台是否共用相机。弧段对比轮廓。校家具体量时，找同景深的已知构件作参照。工程尺寸以模型或正式尺寸资料为准。
- 建筑边界或整体方案变化时，以有效白模重出。已选图中范围受限的调整可使用蒙版并保存合成前后。重复漂移时补同机位控制图，或回到模型确认难判构造，再决定是否继续生成。
- 记录实际输入顺序、每张参考的用途、实际执行提示词、候选取舍、原生输出尺寸和源文件位置。母图、候选和交付图各有独立版本。白模分辨率、原生渲染分辨率和最终导出分辨率分别记录。

## 评审与退回

| 顺序 | 查什么 | 用什么证据 |
| --- | --- | --- |
| 建筑与空间 | 视点、檐边、柱脚、楼板、玻璃内退、平台及水位关系 | 保持画幅，等比归一后与当前白模并排或叠图。关键点做原像素放大 |
| 布置与遮挡 | 家具件数、方向、体量、落地、通行，纱帘前后与室内外分层 | 同一区域原像素裁图，对比用户标注或已选稿 |
| 景观与光 | 岸石入水、树的根干冠连续、水口与落水接续，整体光色 | 全景和重点节点。光感调整时可抽测同位置亮暗 |
| 变更回归 | 本轮修改是否齐全，原有约束是否维持 | 逐项对照最新变更、保护项及上版有效设计 |

回改意见写明「位置与对象 → 现状偏差 → 目标 → 保护项 → 验收对照」。有证据的条目标为通过或待回改。需要尺寸、地面坡度或精确构造依据的条目标为需模型核实。指出有无影响定版的偏差。

**6 号 V33 案例。** 要增设上层内退玻璃幕墙时，用白模轮廓控制长瓦檐和檐底，查看玻璃顶是否在檐后连续收口，并回查平台两张短座、低几、石岸和通道。透视可读之后再评估玻璃反射和暮色。

## 交接单

```text
视角 / 当前机位 / 版本
输入与用途：底图路径、尺寸、哈希（需锁定时）、标注及参考职责
本轮改动与验收点：对象、范围、要求及可见结果
保留 / 撤回：跨轮持续有效的项目、本轮已失效的旧要求
证据：白模对照、原像素局部、必要的边线或遮挡核查
交付：实际文件和尺寸、执行提示词、候选或修订记录
状态：通过项、待修项、需模型核实项，以及选稿或精修授权
```
