# 建筑效果图工作流

把白模、标注、原生渲染、评审证据和 4K 成图按视角及版本串起来。按用户当前任务进入对应阶段。用户只要标注、提示词、评审或精修时，交付该阶段的结果。

## 锁定本轮输入

- 确认当前视角、有效白模或母图、最新变更、必须保留项及已撤回要求。同名白模更新时核对实图和哈希。换机位后，重新判断投影、遮挡、取点和摆位。
- 明确各图的作用。白模控制相机、画幅和原有几何，标注给出本轮改动及边界，参考图提供指定的材质、家具、植栽或光线。用户已选稿的干净局部可传递布置。确认辅助线、色块或体块表达的是硬边界、尺度、方向还是示意。
- 写出可观察的目标和保护项。例如，幕墙内退应露出檐底，顶部收在檐后，右侧檐口越过玻璃立边。画面能验证投影关系和可见性，实际退距和通行净宽回到模型量取。

## 选择阶段

| 用户要做什么 | 执行与交付 |
| --- | --- |
| 标注或整理提示词 | 在干净白模的副本上分开材质、配景与光感，编号关键节点。交付标注、参考图分工及可观察的验收点。读[标注、渲染与评审](references/render-and-review.md)。 |
| 出原生图或按意见回改 | 按有效白模、变更和保留项组织输入。机位或建筑关系漂移时，以白模重出。已选构图的限域调整可用蒙版原位合成，保存对照和修改范围。读[标注、渲染与评审](references/render-and-review.md)。 |
| 评审成图 | 对实际图片先核相机与几何，再看布置、材质和光色。用同画幅对照和原像素局部标明通过项、待修项、证据及回归项。读[标注、渲染与评审](references/render-and-review.md)。 |
| 精修已选稿 | 锁定获准的母图版本、比例和保护项，按构件做重叠分区重建，配准拼合并核查接缝。读[4K 分区精修](references/4k-refinement.md)。 |

## 交接与状态

- 每轮交接记录视角、版本、底图和尺寸、实际输入及用途、变更和保护项、核验依据、交付路径、待修问题。生成阶段附实际调用的提示词和原生输出尺寸。精修阶段附母图哈希、分区与拼合记录及实际成图尺寸。
- 区分试稿、原生图自检、独立评审、用户选稿和精修交付。以用户点名的文件定精修母图。要求试光或生成候选时，另存现有选稿。授权范围以当前任务为准。
- 仅把已生成、已检查的成果写成交付。工具不可用时交付当前可完成的标注、提示词或评审，并写明具体缺口。涉及生成次数、费用或外部操作时，沿用当前任务的授权范围。
